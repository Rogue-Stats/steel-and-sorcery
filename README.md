# Steel & Sorcery

A 16-bit idle RPG inspired by World of Warcraft and Sword x Staff. Pick a race, class and role, quest to level 60, run dungeons, roll Need/Greed for loot, and craft gear with professions.

**Play:** open `index.html` in a browser, or visit the GitHub Pages link for this repo.

On iPhone: open the link in Safari → Share → **Add to Home Screen** to play full screen.

## Notes
- Saves are kept in your browser on each device.
- Group Finder with real players, the player Auction House and cloud saves only work in the Claude-hosted version. Here you play solo with mercenaries and Goblin Traders.
